# Contributing

Each repository describes its own workflow in its `.github/CONTRIBUTING.md`; for the component library that is [andes-ng/andes](https://github.com/andes-ng/andes/blob/main/.github/CONTRIBUTING.md).

The short version, common to every repository in this organization:

- Branch names are `feature/*`, `bugfix/*`, `hotfix/*` or `release/*`; work lands in `develop` and releases are cut from `develop` into `main`.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org) and are checked on commit.
- A pull request describes what changed and why, passes the checks, and updates tests and docs with the code.
- Be kind: see the [Code of Conduct](./CODE_OF_CONDUCT.md).
